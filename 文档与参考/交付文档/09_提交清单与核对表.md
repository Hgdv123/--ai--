## 二、提交包内容清单

整个 `文脉ai助手/` 文件夹即提交物。**代码单独成一个可独立运行的文件夹**，与其余材料分开：

```
文脉ai助手/
│
├─ 提交说明.md                        ← 30 秒导读：怎么跑、东西在哪
├─ 文脉_作品封面.png
│
├─ 代码/                              ★ 代码单独一组，自身可独立运行
│   ├─ 源程序/                        ← 程序包（21 模块）+ 界面 + 随包资源
│   │   ├─ web/index.html             ← 单页交互界面
│   │   ├─ models/                    ← 随包本地模型（2,545.9 MB）
│   │   │   ├── qwen2.5-3b-q4_k_m.gguf
│   │   │   ├── qwen2.5-0.5b-q4_k_m.gguf  ← 投机解码草稿模型
│   │   │   ├── bge-small-zh-q8_0.gguf
│   │   │   └── bin/llama-server.exe 等
│   │   └── wheels/                   ← 53 个离线依赖包（362.3 MB，覆盖 cp39–cp313）
│   ├─ 测试/                          ← 测试套件（36 个脚本：16 个套件 + 独立脚本 / 诊断 / 验收 / 基础设施）
│   ├─ 评测/                          ← 评测脚本与结果（可复现）
│   │   ├─ run_eval.py / README.md
│   │   ├─ results/                   ← report.md + latest_*.json
│   │   └─ external/                  ← 外部验证集投放目录（当前为空）
│   ├─ README.md                      ← 上手说明（环境要求 / 命令速查 / 已知限制）
│   ├─ pyproject.toml                 ← 依赖声明
│   ├─ .env / .env.example            ← 环境变量（**提交版为占位符，无真实密钥**）
│   ├─ _launch.py                     ← 启动器（定位包、检查依赖、起服务）
│   ├─ 启动文脉.bat                    ← **唯一入口，双击即启动**
│
├─ 数据与产物/
│   ├─ data/                          ← 示例文献库（6 篇论文 + 6 个 PDF + 解析结果）
│   └─ outputs/                       ← 已生成产物（综述稿、自检报告、Word、Excel）
│
└─ 文档与参考/
    ├─ 交付文档/
    │   ├─ 01_模型与算法说明.md        ★ 赛题硬性
    │   ├─ 02_验证集评测结果.md        ★ 赛题硬性
    │   ├─ 03_阿里云方案与使用情况.md
    │   ├─ 06_数据与合规说明.md
    │   ├─ 08_Demo演示脚本.md          ← 录屏/现场演示用
    │   ├─ 09_提交清单与核对表.md      ← 本文件
    │   └─ 10_风险清单与应对.md        ← 已发生事故留档 + 已知限制
    ├─ 参考资料/
    │   ├─ 文脉_方案_v1.1.md            ← 完整产品方案（定位/功能/技术/边界）
    │   ├─ 阿里云资源状态.md            ← 阿里云资源与用券情况
    │   ├─ 交接文档.md                  ← 交接记录（历史，含目录改名说明）
    │   └─ 交接说明.md                  ← 交接说明（历史）
    └─ 界面截图/                        ← 7 张界面截图 + `_过程截图/` 3 张（共 10 个 PNG）
```

> **哪些名字不能改？**
> `data/` 与 `outputs/` 必须叫这个名字——程序按 `<数据目录>/data`、`<数据目录>/outputs` 查找，
> 改名会找不到数据。`代码/源程序/`、`代码/`、`文档与参考/` 都可以自由改名或整理，
> 启动器是按「目录里有 `__main__.py`」来找包的，不依赖目录名。
> 数据目录的位置由启动器通过 `WM_ROOT` 指定，所以把 `数据与产物/` 整个挪走也仍然可用。

## 四、已知限制（如实列出，供评审参考）

写在这里而不是藏着，是因为它们会影响评审的判断，提前说明比被问出来好。

| 限制 | 影响 | 当前状态 |
|---|---|---|
| **否定式论断易误报** | 「所有方法均未超越 X」这类表述可能被判无支撑 | 已在界面与文档中明确提示，并把原文片段交给用户自行判断 |
| **支持率不是固定值** | 论断核对未固定 seed，同一草稿连跑实测 0.73–0.91 摆动 | 不报单一支持率作为成绩；界面给出原文片段与页码，由用户判断 |
| **「原文明确矛盾」判据偏保守** | 只认数值与方向这类能站得住的冲突，文字层面的矛盾可能漏报 | 界面同时给出原文片段，以用户看到的内容为准 |
| **验证集规模偏小** | 6 篇论文 + 4 类注入错误（各 1 处），只能验证功能正确性，不足以外推精度 | 已预留 `代码/评测/external/` 接口，说明扩展方式 |
| **扫描版 PDF 不支持** | 无文字层的 PDF 会落到「无正文」状态 | 界面明确提示，不算失败 |
| **超长文档截断** | 超过 200 页会被截断 | 已知行为，`_MAX_PARSE_PAGES=200` |
| **本地模型质量弱于云端** | 离线模式正文更保守，需逐句核对 | 界面有质量提示；仅当本地模型也不可用时才退回"论文清单"式输出 |
| **首次启动需读论文** | 首次约 20 秒（已含内容就绪） | 界面有启动提示与自动刷新 |
| **提交包体积 2.92 GB** | 实测 2,987.3 MB、3,607 个文件：随包本地模型 2,545.9 MB + 离线依赖 wheels 362.3 MB + 嵌入缓存 46.7 MB（3,357 个文件）+ 权威数据与产物 13.6 MB + `代码/data`、`代码/outputs` 下的测试沙箱副本 13.5 MB + 源码/网页/文档 5.4 MB | 若平台有上传上限，可移除 `代码/源程序/models/` 转为纯云端版（功能不受影响，仅失去离线能力），体积降至约 140 MB |
