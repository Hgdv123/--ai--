## 4. 本次会话修掉的 5 个真 bug（都有实测证据）

### 4.1 离线模式报「模型不可用」（用户首次报障）

- **根因**：`agent._chat_with_tools()` **完全没有本地分支**，永远拿 `settings.api_key` 请求阿里云端点。Key 是中文占位符 → `urllib` 按 latin-1 编码请求头 → `UnicodeEncodeError` → 放弃。更前面还有一道闸：`run()` 判断 `if not self.client.available`，而 `available` 用 `bool(api_key)` 判断，占位符"非空"即被当成可用。
- **那句话从头到尾不成立**：本地模型一直是好的。
- 「云端是否可用」在 `agent.py` / `llm.py` / `config.py` **三处各写一遍、各错一遍**，已统一到 `config.key_usable()`。
- **修**：`_chat_with_tools()` 加本地分支；`run()` 闸门改为 `client.available or local_llm.available("gen")`。

### 4.2 `_healthy()` 把「忙」当成「没起来」

- **根因**：探活超时仅 2 秒且只认 HTTP 200。llama-server 在大提示词推理时无暇应答 `/health` → 被判"没起来" → `_start()` 另起实例抢同一端口 → 必然失败 → 报"未就绪或返回异常"。
- **修**：有 HTTP 应答即算活着（503 = 忙）；但**端口在监听 ≠ 已就绪**（llama-server 先监听、后加载模型，该窗口请求回 503），就绪一律以 `/health` 返回 200 为准。
- **实测**：真实推理期间探测 37 次，37/37 判为活着；端口上始终 1 个实例。

### 4.3 启动脚本崩溃（当时自己引入的回归）

- **根因**：把 `python -X utf8 -m 源程序` 替换为实际包名时，**`%` 的优先级高于 `+`** —— `"…%s…" + PKG + "…" % data_dir` 里的 `%` 只作用于最后一段 → `TypeError: not all arguments converted during string formatting` → `cmd_demo` 崩 → **服务根本起不来**。
- **教训**：改打印文案后必须真跑一次启动，`py_compile` 通过不代表能跑。

### 4.4 主按钮永久变灰（用户报"点不了"）

- **根因**：`btn-run` 在 HTML 里默认 `disabled`，只有 `refresh()` 成功才解开；而**服务不可达时 `refresh()` 直接 return**，那句"解开按钮"永远执行不到。
- **修**：失败分支也解开按钮并提示「服务尚未就绪，正在自动重试」；首屏不再写死 `disabled`；生成中不用 `disabled` 而用 `.running` 样式 + **15 分钟看门狗**自动复位。

### 4.5 降级原因被误报成「离线模式」（用户报"为什么提示离线"）

- **根因**：前端用 `/本地|不可用|关闭/` 判断降级，而"云端输出被一致性检查否掉"的说明里含「**本地**模板」四字 → 误报成离线模式，还补了一句"离线模式不会调用大模型"（与事实相反）。
- **真实链条**：云端调用**成功** → 输出与文献卡片对不上（2/6 句有依据，低于 35% 阈值）→ 退回模板。
- **修**：后端标记 `fallback_reason`（`offline` / `model_failed` / `ungrounded`），`/api/state` 透出，前端按原因分三种文案。

### ⚠️ 必须记住：`.env` 不热加载

`.env` **只在进程启动时读一次**。改完必须**重启程序**（关掉命令行窗口、重新双击「启动文脉.bat」）才生效 —— 这一条让人踩过坑：改完 `.env`、切到云端、点生成，看到"离线模式"提示以为是 Key 无效，其实只是没重启。界面与 `.env.example` 里都已写明。

### 可复现性设计（别改回去）

草稿原先用 `temperature=0.3` 采样 → 两次生成相似度仅 77.3% → 被审对象每次都变 → 自检结论每次都变（用户合理追问"为什么两次审查不一样"）。

排查结论（都是实测）：
1. 同一份稿子连测两次 → 判断**稳定**；
2. 温度改 0 → **仍变**；
3. 温度 0 + 固定 seed：短生成三次全同，**长生成仍变**；
4. 多槽 `-np` 降到 1 → **仍变**。**llama.cpp 在 CPU 上无法保证长序列逐位可复现。**

**最终方案**：让本地生成**也走缓存**（原先只有云端走），同一输入第二次直接复用。
相关开关：`WM_DRAFT_TEMPERATURE`（默认 0）、`WM_DRAFT_SEED`（默认 20260918）。
**边界**：缓存让同一输入可复现；换一批文献仍会生成不同草稿 —— 这是生成式模型的本性，**不要承诺"任何输入都一模一样"**。
